# Library of Congress handwritten transcription drafts

This repository contains **6,477 machine-generated page transcription drafts** for handwritten Library of Congress material. These files are OCR drafts, not official Library of Congress transcriptions or verified ground truth. Human review is required before quotation, publication, or use as supervised training labels.

## Collections

- `LOC_ANNA_MARIA_BRODEAU_THORNTON_TRANSCRIPTIONS/`: 423 text drafts.
- `LOC_CHARLES_HAMLIN_TRANSCRIPTIONS/`: 1,463 text drafts.
- `LOC_MARGARET_BAYARD_SMITH_TRANSCRIPTIONS/`: 1,330 text drafts.
- `LOC_SAMUEL_F_B_MORSE_TRANSCRIPTIONS/`: 3,261 text drafts.
- `LOC_TRANSCRIPTION_METADATA/`: shared CSV and JSONL provenance for all 6,477 drafts.

The metadata provides direct Library of Congress page, item, and IIIF image URLs. Scan images are not duplicated in the collection folders.

The separate expanded Hamlin index-digest reread is intentionally excluded.
